
```
PROMPT 1: Complete Energy Consumption Analysis Analyze the provided
campus energy-consumption dataset for a Campus Energy Saving System
project. Calculate total, average, minimum, and maximum electricity
consumption. Compare consumption across buildings, departments,
classrooms, laboratories, hostels, offices, and other campus areas.
Identify the highest and lowest energy-consuming areas. Analyze daily,
weekly, and monthly trends where data is available. Identify unusual
consumption patterns, possible energy wastage, peak-demand periods, and
areas requiring immediate attention. Present the findings in clear
tables and explain the meaning of each major trend in simple language.
Conclude with practical recommendations for reducing electricity
consumption.
```

```
PROMPT 2: Building/Department Comparison Compare electricity consumption
among all campus buildings or departments in the dataset. Rank them from
highest to lowest consumption and calculate each area’s percentage
contribution to total campus consumption. Identify possible reasons for
high or low usage based on the available data. Recommend targeted
energy-saving actions for each high-consumption area.
```

```
PROMPT 3: Energy Wastage Detection Analyze the dataset to identify
possible energy wastage. Look for unusually high consumption,
consumption during non-working hours, sudden spikes, repeated abnormal
patterns, unnecessary lighting or cooling usage, and differences between
expected and actual consumption. Clearly distinguish between confirmed
findings and possible explanations. Provide practical actions that could
reduce the identified wastage.
```

```
PROMPT 4: Before-and-After Energy Saving Analysis Compare campus
electricity consumption before and after implementing energy-saving
measures. Calculate absolute and percentage changes in consumption,
average savings, peak-demand changes, and estimated cost savings.
Identify which measures appear most effective. Explain the results in a
professional report format and mention any limitations in the dataset.
```

```
PROMPT 5: Cost-Savings Analysis Using the provided
electricity-consumption data and electricity tariff information,
estimate the campus electricity cost. Calculate potential savings from
reducing consumption by 5%, 10%, 15%, 20%, and 25%. Present the results
in a table and explain which reduction target provides a realistic
balance between savings and implementation effort.
```

```
PROMPT 6: Trend and Forecast Analysis Analyze historical campus
electricity consumption and identify daily, weekly, monthly, seasonal,
or academic-period trends. Identify recurring peak periods and
low-consumption periods. If sufficient data is available, create a
simple forecast for future consumption and explain the assumptions used.
```

```
PROMPT 7: KPI Analysis Create important Key Performance Indicators for a
Campus Energy Saving System, including total consumption, average
consumption, peak consumption, percentage reduction, cost per kWh,
estimated savings, consumption per building, and consumption per student
where relevant. Explain each KPI and identify which KPIs should be
monitored regularly.
```

```
PROMPT 8: Data Quality Check Check the provided campus energy dataset
for missing values, duplicate records, inconsistent units, incorrect
dates, unusual values, and other data-quality problems. Explain how each
issue could affect the analysis and recommend corrections before making
final conclusions.
```
